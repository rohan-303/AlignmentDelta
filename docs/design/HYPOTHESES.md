# Hypotheses

**H1 — safety-direction interaction:** The relationship between signed intervention dose and non-refusal primary outcomes differs between the refusal direction and matched orthogonal random directions. A null interaction is an interpretable result.

**H2 — cross-family response:** The dose-response curve for the primary safety-discrimination outcome and the calibration outcome varies by model family/checkpoint, without treating one checkpoint as a universal family effect.

**H3 — onset separation:** The dose at which refusal/boundary behavior changes is not assumed to equal the dose at which calibration or semantic consistency changes; the planned analysis estimates their curve features and permits no separation.

Each hypothesis has a prespecified contrast and uncertainty interval in the statistical plan. No hypothesis asserts that safety-targeted intervention must degrade utility or calibration.
