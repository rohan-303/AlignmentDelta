# Experiment status taxonomy

Future run records should use one of these statuses:

- **planned** — specified but not executed.
- **pilot** — exploratory execution used to test implementation, feasibility, or protocol details; not automatically confirmatory evidence.
- **completed** — execution completed according to the declared protocol and produced auditable outputs.
- **failed** — execution did not successfully complete. The run record and failure information must remain available.
- **invalidated** — execution completed but was later determined scientifically unusable because of a documented protocol violation, corrupted input, implementation defect, or equivalent reason. Its record must not be deleted.

This taxonomy is documentation only in Step 1.0; no run database is implemented.
