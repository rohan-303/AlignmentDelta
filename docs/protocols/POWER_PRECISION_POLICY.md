# Power and precision policy

No variance or effect estimate is claimed now. Confirmatory sample size will be set from fixed computational budget and/or precision targets for confidence intervals, supported by simulations over a predeclared plausible effect grid. Literature-derived variance may be used only when the construct, unit, and evaluator match; technical pilot variance may inform measurement precision and runtime, not select a favorable scientific effect.

Pilot outcome direction or magnitude may not be used to shrink, expand, or otherwise tune confirmatory sample size after seeing treatment effects. Any pilot-informed planning input must be frozen before confirmatory labels are inspected and documented with sensitivity analyses. If no defensible variance exists, report a transparent detectable-effect/precision analysis rather than fabricated power.
