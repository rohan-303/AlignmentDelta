# Exploratory pilot purpose

**Status: frozen before outcome execution.**

The exploratory pilot exists to verify scientific measurement plumbing, estimate basic variance/response-curve behavior, detect floor/ceiling problems, and validate analysis code before confirmatory execution.

It does not test final hypotheses, establish significance, support publication claims, select outcomes because they look interesting, tune alpha based on favorable effects, or choose checkpoints based on results.

Pilot observations must remain segregated from confirmatory data and must be labeled exploratory in every manifest and report.
