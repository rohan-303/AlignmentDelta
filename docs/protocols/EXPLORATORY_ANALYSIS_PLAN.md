# Exploratory pilot analysis plan

Analysis is descriptive and plumbing-oriented only. Report response curves, baseline-adjusted changes, refusal-direction versus random-reference differences, item-cluster bootstrap confidence intervals, variance estimates, floor/ceiling diagnostics, scorer failures, missingness, and technical anomalies.

The unit for resampling is the source item or source-item pair, not individual generated tokens or duplicated alpha=0 condition rows. Exploratory intervals are descriptive; no final hypothesis significance claim, confirmatory Holm procedure, or empirical random-direction p-value is primary. Pilot data cannot be promoted to confirmatory data without a separately versioned protocol.
