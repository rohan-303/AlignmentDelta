# Random-control statistical audit — Step 2.4

Random controls are not an exchangeable label-permutation null because the refusal direction is selected using refusal-related data and random directions are generated from a different construction.

Use four directions for pilot software/technical validation. Use a provisional sixteen-direction reference bank for confirmatory planning, subject to precision review. Treat random directions as a sampled reference factor and estimate item-cluster bootstrap confidence intervals for refusal-direction minus mean-control contrasts.

Do not use empirical-null p-values from sixteen directions as the primary confirmatory significance test: plus-one resolution is `1/17`, which cannot reach `0.05`. No ordinary refusal/random permutation test appears in the primary protocol.
